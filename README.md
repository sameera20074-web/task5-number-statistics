# VEDA TASK 5 - Number Statistics

## 📌 Description
Create a Python program that identifies even and odd numbers and finds the largest and smallest numbers in a given list.

## 🎯 Objective
Practice loops, conditions, and basic numerical processing.

## 📊 Results
- Input: [15, 22, 8, 91, 34, 67, 50, 11, 88, 3]
- Even: [22, 8, 34, 50, 88] - 5 numbers
- Odd: [15, 91, 67, 11, 3] - 5 numbers
- Largest: 91
- Smallest: 3

## 💡 Logic Used
- Modulo operator (%) to check even: num % 2 == 0
- For loop to process each number
- max() and min() for largest/smallest

## 🛠 Tools
Python, Jupyter Notebook

## ▶️ Run
python number_statistics.py

## 📚 Learnings
- Even/Odd identification
- List filtering
- Numerical analysis with loops
